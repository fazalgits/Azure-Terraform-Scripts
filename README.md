# Azure Terraform Scripts

## 📌 Project Overview
This project demonstrates how to create Azure infrastructure using Terraform.  
Instead of manually creating resources in Azure, we use Infrastructure as Code (IaC).

---

## 🛠️ Resources Created
- Resource Group
- Virtual Network
- Subnet
- Public IP Address
- Network Interface
- Linux Virtual Machine (Ubuntu)

---

## ⚙️ Tools Used
- Terraform
- Microsoft Azure
- Visual Studio Code
- GitHub

---

## 🚀 Steps to Run the Project

1. Initialize Terraform:
   terraform init

2. Validate configuration:
   terraform validate

3. Preview changes:
   terraform plan

4. Apply configuration:
   terraform apply

---

## 🔐 Notes
- .gitignore is used to avoid pushing sensitive files like Terraform state files.
- SSH key is required to access the virtual machine.
